# Adding AI Screen Assistant to Taskbar

## Quick Start

The app is now running! To add it to your taskbar:

### Method 1: Using the Batch File (Shows Console)
1. Right-click on `start_ai_assistant.bat`
2. Select "Pin to taskbar"
3. The batch file will appear in your taskbar

### Method 2: Using the VBScript (No Console Window - Recommended)
1. Right-click on `start_ai_assistant.vbs`
2. Select "Pin to taskbar"
3. The app will launch without showing a console window

### Method 3: Create a Shortcut
1. Right-click on `start_ai_assistant.bat` or `start_ai_assistant.vbs`
2. Select "Create shortcut"
3. Right-click the shortcut → "Properties"
4. Click "Change Icon" if you want to customize the icon
5. Drag the shortcut to your taskbar

## Notes

- The VBScript launcher (`start_ai_assistant.vbs`) runs the app without showing a console window, which is cleaner for taskbar use
- The batch file (`start_ai_assistant.bat`) shows the console window, which is useful for debugging
- Make sure Python is in your PATH, or update the batch/VBScript files to use the full path to Python

## Customizing the Icon

To add a custom icon:
1. Create or download an `.ico` file
2. Right-click the shortcut → Properties → Change Icon
3. Browse to your `.ico` file
